Device type: Corporate
  1. Open Windows Configuration Designer

    Free from the Microsoft Store. Use your own Windows 10 or 11 PC, not a device you plan to lock down.

  2. Add these values

    AuthPolicy OnPremise tells Windows this server checks the secret. The server URL is the discovery address. Leave the enrollment URL and policy URL empty. The secret is the token password. Set the UPN to any address such as device@lab.test.

  3. Export and apply

    Export the provisioning package. Install that .ppkg on the device you want to enroll. This computer is already enrolled, so use another device for a new enrollment.
